## 一、怎么玩（手机）

把 `index.html` 传到手机 → 用手机浏览器打开即可（三张鬼脸已 base64 内嵌，**只要这一个文件**）。
局域网方式：本目录执行 `python -m http.server 8000`，手机同 WiFi 打开 `http://电脑IP:8000/index.html`。

### 严格横屏（重要）
本作**只支持横屏，竖屏无法游玩**（取消了竖屏玩法）：

- 点「进入」后会请求全屏并尝试锁定横屏（Android Chrome / Edge / 三星浏览器支持）。
- 如果手机是竖着的（或系统开了「竖屏锁定」），会直接弹出全屏提示「请把手机横过来」，并且**游戏完全冻结**（倒计时、三个鬼、体力全部暂停）。
- 把手机转成横屏后自动继续；如果系统锁定了竖屏，请在系统下拉菜单里关掉「方向锁定/竖屏锁定」，再点提示里的「我已横过来 · 重试」，或点屏幕任意位置重试锁定。
- iPhone 的 Safari 不支持网页锁定横屏，必须手动把手机横过来（游戏会一直等着你）。

### 操作

| 操作 | 手机 | 电脑 |
| --- | --- | --- |
| 移动 | 左半屏按住 → 虚拟摇杆 | WASD / 方向键 |

### 目标
1. 在 **35×35 随机迷宫**里找回 **8 张记忆碎片**（会发光的宝丽来照片，靠近有提示音）。
2. 集齐后走廊尽头的**铁门解锁**，红色光点指路。
3. 走进铁门 → 逃出，按用时评 S / A / B / C，记录存在本地。

手电照得远，但**开灯更容易被鬼发现**；关灯蹲黑能跟丢它们。电量耗尽要等回充。

## 二、三个鬼（就是那三张照片）

| 鬼 | 照片 | 特点 |
| --- | --- | --- |
| **笑面鬼** | 戴眼镜、蓝衣那张 | 会**瞬移**到你背后/视野外，靠近有笑声。速度中等。 |
| **低语鬼** | 白外套侧脸那张 | **跑得最快**、视野最远，一直念你的名字，最难甩掉。 |
| **倒挂鬼** | 俯视猫耳滤镜那张 | 挂在天花板高度飘行，视野极广，靠近时**手电疯狂失灵 + 抽走电量**。 |

**三个鬼开局就在你附近，第一秒起全速追杀**，而且开局有 **10 秒保护期**：

- 保护期内三个鬼会一直朝你扑，但被挡在 **2.6 格**之外，碰不到你（相当于一圈护罩），你可以趁机认清方向再跑。
- 屏幕顶部有倒计时徽章（`保护期 9 秒 · 它们碰不到你`），最后 3 秒会变红并每秒“嘀”一声，画面边缘有一层淡蓝色护罩。
- 10 秒一到：提示「保护期结束 —— 它们可以碰到你了」+ 一声尖啸 + 手机震动，之后被抓到就是死亡。
- 保护期内心跳和恐惧上升更慢，方便你判断方位。
- 想改时长/护罩距离：搜 `const PROTECT_TIME=10` 和 `const PROTECT_RING=2.6`。
碰到任何一个都是死亡，死亡界面会显示是谁抓到了李丰壕。

突脸沿用三张真实照片（高对比 + 抖动放大 + 尖叫音效），另外还有灯光爆闪、门板砸响、耳边低语、天花板刮擦、鬼影一闪。
默认「标准」大约 **8～17 秒一次惊吓**，鬼发现你的瞬间还有约 40% 概率直接甩脸。

## 三、听声辨位（新）

- **左右声道**：鬼的脚步声、心跳会按它相对你的方位实时分配到左/右耳机，越近越响、节奏越快。
- **底部方位条**：屏幕下方有一条方位尺，正中间是「正前方」，鬼的位置会有对应颜色的光点 + 波纹，
  并显示文字（例如 `脚步 · 左前方 · 很近 · 低语鬼`）。
- 正后方时左右声道会并到一起（现实里也分不出来），这时靠方位条判断。
- 想在设置里关掉更硬核：**听声辨位 → 关闭**。

> 强烈建议戴耳机，这个提示完全是给耳机设计的。

## 四、设置

- **难度**：安魂曲 / 低语 / 深渊 —— 鬼的速度、视野、抓人判定、瞬移频率、耗电速度。
- **惊吓强度**：轻微 / 标准 / 强烈 / 疯狂（几乎不停）—— 突脸概率与间隔、震动幅度。
- **画质**：省电 / 均衡 / 清晰。
- **音效**：开启 / 静音。
- **听声辨位**：开启（推荐）/ 关闭。

## 五、地图与实体墙

- 迷宫每次随机生成（递归回溯 + 环路 + 8 个房间），出口永远在离起点最远的那头。
- **墙是实体**：角色是有半径的圆，四角分别与格子碰撞，撞墙只会贴着墙滑动，**穿不过去**，撞墙有闷响与镜头轻震。
- 鬼用同一套格子做 BFS 寻路，目标点会自动吸附到可通行格，不会卡墙。
- **墙面是不透明的**：手电筒照亮时，墙面按「贴图 × 光照」不透明绘制（早期版本会把上一列变暗用的透明度带到下一列，
  导致墙面像玻璃一样透出地板/天花板颜色，已修复）。鬼被墙挡住时也不会透出来。

## 六、文件说明 / 想换照片

```
index.html              ← 游戏本体（单文件，可直接发到手机玩）
assets/ghost1..3.jpg    ← 你发来的三张原图
assets/face1..3.jpg     ← 裁好的三张鬼脸（游戏实际用这个尺寸）
tools/embed_faces.py    ← 换脸脚本
预览/                   ← 截图
```

换照片：用新的 `face1.jpg / face2.jpg / face3.jpg`（正方形、人脸居中）替换 `assets/` 里的，然后运行 `python tools/embed_faces.py`。

常用微调位置（都在 `index.html` 里）：
- 三个鬼的名字/速度/特性/台词 → 搜 `GHOST_DEFS`
- 惊吓间隔与出脸概率 → 搜 `const SCARE=`
- 地图尺寸、碎片数量 → 搜 `const MAPW=`、`const KEYS_NEED=`
- 难度（鬼速/视野/耗电） → 搜 `const DIFFS=`
